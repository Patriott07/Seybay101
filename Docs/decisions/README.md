# Architecture Decision Records

Gunakan folder ini untuk keputusan yang memengaruhi lebih dari satu task atau subsystem.

Buat file berdasarkan template `Docs/templates/adr.md`, misalnya:

```text
Docs/decisions/ADR-0001-rule-engine-source-of-truth.md
```

ADR harus menjelaskan context, evidence, keputusan final, konsekuensi, dan alternatif yang ditolak. Jika keputusan berubah, jangan menghapus ADR lama; ubah statusnya menjadi `Superseded` dan buat ADR baru.
