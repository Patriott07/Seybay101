# Task Workspace

Setiap pekerjaan yang membutuhkan analisis dan perubahan dibuat sebagai folder:

```text
Docs/tasks/TASK-XXXX-short-name/
├── plan.md
├── status.md
└── review.md
```

Mulai dari template di `Docs/templates/`. Jangan membuat task baru untuk catatan biasa; gunakan task folder bila ada perubahan code, data, scene, atau behavior.

## Naming

- `TASK-0001-medical-check`
- `TASK-0002-save-load-repair`
- `TASK-0003-day-5-rules`

Satu folder hanya untuk satu outcome yang dapat diverifikasi.
